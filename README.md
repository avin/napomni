# Напоминания Windows

Нативное приложение на Rust и GPUI Kit 0.7.3: напоминания через русский чат, локальный планировщик, трей и постоянные тосты. Сохранённые расписания работают без интернета и LLM.

## Запуск

Нужны Windows 10/11, Rust с целью `x86_64-pc-windows-msvc`, Visual Studio Build Tools с C++ и Windows SDK, графический адаптер с поддержкой DirectX.

```powershell
cargo run --locked
```

Приложение запускается в трее. Двойной щелчок по синему колокольчику открывает главное окно; закрытие окна оставляет приложение работающим. Полное завершение — «Выход» в меню трея; оно закрывает тосты и останавливает сигнал.

Открыть главное окно сразу:

```powershell
cargo run --locked -- --open
```

Для постоянного использования соберите `cargo build --release --locked` и запускайте `target/release/win-notifi-toast.exe`. Автозапуск сохраняет путь текущего исполняемого файла: включайте его из той копии, которой будете пользоваться.

## Подключение и команды

В разделе «Настройки» задайте базовый URL OpenAI-совместимого API, API-ключ и ID модели. Ключ скрыт на экране. «Проверить» проверяет настоящий безопасный вызов инструмента. Для чата требуются Chat Completions и tool calling. Можно загрузить каталог моделей и искать по части имени или ID; при недоступности каталога остаётся ручной ввод. У OpenRouter учитываются метаданные инструментов, неизвестные возможности требуют проверки подключения.

В разделе «Напоминания» список и чат расположены рядом. Фильтры отделяют активные, приостановленные и завершённые записи. Enter отправляет текст. Кнопка «Изменить» у записи прикрепляет её к следующей команде.

API-ключ по согласованному решению хранится открытым текстом в конфиге; в историю чата он не записывается. Запросы выполняются в фоне. История сохраняется до ручной очистки.

Если API не вернул итоговый ответ, уже выполненные изменения остаются сохранёнными и видны в списке и чате. «Продолжить ответ» повторяет получение ответа без повторного выполнения сохранённых операций; продолжение доступно и после перезапуска. Уточнение сохраняет выбранную запись.

Примеры команд:

- «Напомни “Выпить воды” через 20 минут».
- «Напомни завтра в 10:00 позвонить».
- «Напоминай размяться каждые полчаса с 09:00 до 18:00 по будням».
- «Напоминай проверить задачи каждые две недели по вторникам и четвергам в 10:00, начиная с недели 19 октября 2026 года».
- «Каждый месяц 31-го в 12:00 напомни проверить отчёт».
- «Каждый год 29 февраля в 09:00 напомни о событии».

Можно указать несколько времён, период дат, исключённые даты, цвет рамки и звук. Будни означают понедельник–пятницу. Границы периодов и окон времени включительны. Невозможные даты пропускаются. Неподдерживаемые или неоднозначные правила требуют уточнения и не подменяются приблизительными. Окна через полночь задаются как неподдерживаемая комбинация; поиск ограниченного расписания имеет явные вычислительные пределы, описанные в протоколе задачи 09.

Кнопка «Изменить» прикрепляет конкретную запись к команде чата. «На паузу/Возобновить», удаление и отмена последнего изменения вызывают те же операции ядра, что инструменты LLM. Отмена меняет данные, не возвращая закрытые карточки. Уже открытый тост сохраняет прежние текст, цвет и звук. Завершённые однократные записи доступны отдельно.

Относительное время отсчитывается от отправки команды. Календарные часы следуют местному времени Windows, интервалы сохраняют исходную сетку. Сон и остановка приложения не приводят к догоняющим уведомлениям; компьютер ради напоминаний не пробуждается.

## Тосты и настройки Windows

Тосты остаются до закрытия; одного напоминания одновременно открыт максимум один тост. Новая карточка появляется впереди, наведение раскрывает стопку. Прокрутка даёт доступ ко всем карточкам, включая длинный текст. Карточку можно закрыть кнопкой или горизонтальным перетаскиванием. Меню трея позволяет явно перейти к стопке с клавиатуры; подсказки управления доступны в протоколе задачи 11.

Все звучащие карточки используют один встроенный повторяющийся сигнал. Он прекращается после закрытия последней звучащей карточки; беззвучные карточки его не удерживают.

В разделе «Настройки» доступен переключатель автозапуска при входе в Windows. Диалог «Размещение тостов» позволяет выбрать монитор и угол экрана. По умолчанию стопка справа вверху основного монитора. Расчёт учитывает рабочую область, панель задач и DPI. Светлая и тёмная темы следуют Windows; поля, кнопки и иконки используют GPUI Kit, карточки тостов имеют скруглённые углы. Появление тостов не активирует окно.

Демонстрация той же стопки без создания напоминаний:

```powershell
cargo run --locked -- --test-toasts
```

Через пять секунд появятся три тестовые карточки; повторная демонстрация сохраняет уже открытые карточки.

## Локальные данные

- `%APPDATA%/win-notifi-toast/`: подключение, история, напоминания и данные восстановления чата.
- `%APPDATA%/WinNotifiToast/placement.json`: монитор, угол и настройка автозапуска.

Тосты не восстанавливаются после перезапуска. Автозапуск использует пользовательский ключ Windows `HKCU/Software/Microsoft/Windows/CurrentVersion/Run`.

## Проверки

```powershell
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
```

Тесты вызывают публичные операции ядра с управляемым временем и локальный HTTP-стенд; платные запросы к провайдеру не требуются. Проверки настоящих эффектов Windows запускаются отдельно и по умолчанию пропущены. Нативная проверка стопки подтвердила регион окна и сохранение активного окна; захват GPUI через Computer Use завершился таймаутом. Визуальная приёмка и физическая слышимость явно отделены от успешных автоматизированных проверок.
