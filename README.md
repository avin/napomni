# Напоминания Windows

Нативное приложение на Rust и GPUI 0.2.2 (DirectWrite). Первый сценарий: трей, главное окно и три тестовых тоста. Планировщик, сохранение напоминаний, LLM и звук пока не реализованы.

## Запуск

Нужны Windows 10/11, Rust с целью `x86_64-pc-windows-msvc`, Visual Studio Build Tools с инструментами C++ и Windows SDK. Для GPUI требуется поддерживаемый графический адаптер и драйвер DirectX.

```powershell
cargo run --locked
```

Приложение запускается в трее. Если значок скрыт, раскройте область дополнительных значков панели задач. Двойной щелчок по синему колокольчику открывает главное окно. Правый щелчок открывает меню: «Открыть напоминания», «Показать тестовые тосты», «Выход».

Для непосредственного открытия главного окна:

```powershell
cargo run --locked -- --open
```

Закрытие главного окна скрывает его, сохраняя работу приложения и открытые тосты. Полное завершение — «Выход» в меню трея. Выпуск без консольного окна: `cargo build --release --locked`, затем `target/release/win-notifi-toast.exe`.

## Тестовые тосты

Нажмите «Показать тестовые тосты» в главном окне или меню трея. Через пять секунд появятся три карточки. За это время переключитесь в редактор текста и продолжайте печатать: появление карточек должно сохранить фокус и ввод в редакторе.

Тот же сценарий из командной строки:

```powershell
cargo run --locked -- --test-toasts
```

Карточки располагаются справа вверху рабочей области основного монитора. Панель задач исключается из рабочей области через `GetMonitorInfoW`; размеры переводятся из логических в физические пиксели по DPI монитора. Отдельные окна карточек имеют прозрачный фон, скруглённую нативную область и флаги `WS_EX_NOACTIVATE`, `HWND_TOPMOST`, `SWP_NOACTIVATE`. Между окнами карточек нет перекрывающего рабочего стола контейнера.

Каждая карточка закрывается кнопкой «Закрыть ×». Автозакрытия нет. Повторная демонстрация при оставшихся открытых карточках ничего не меняет; для новой демонстрации закройте все три. Если рабочая область не вмещает три карточки, приложение показывает сообщение об ошибке.

Цвета берутся из текущей темы окна Windows; изменения темы обрабатывает GPUI. Шрифт — Segoe UI. Окончательная оценка чёткости требует визуальной проверки на целевом экране.

## Проверки

```powershell
cargo fmt --check
cargo check --locked
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
```

Прикладного ядра в этой задаче ещё нет. Автоматизированные тесты внутренних GPUI-элементов не добавляются согласно согласованной границе тестирования. Проверки настоящих окон и результаты текущего прогона описаны в [протоколе задачи 01](docs/verification/01-gpui-tray-toast.md).
