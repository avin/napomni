# Napomni

Napomni — программа для Windows 10 и 11, которая напоминает о делах всплывающими карточками поверх окон. Напишите в чате,
о чём и когда напомнить: один раз, через равные промежутки или по расписанию.

Карточка остаётся на экране, пока вы её не закроете. Для важных дел можно включить повторяющийся звуковой сигнал.
Сохранённые напоминания работают без интернета, пока программа запущена.

## Первый запуск

1. Запустите `napomni.exe`. В области уведомлений рядом с часами появится синий колокольчик. Если его не видно,
   раскройте скрытые значки.
2. Дважды щёлкните по колокольчику, чтобы открыть окно программы. Ещё один способ: нажмите на значок правой кнопкой и
   выберите «Открыть напоминания».
3. Откройте «Настройки» и подключите ассистента по инструкции ниже.
4. Перейдите в «Напоминания», введите сообщение в чат и нажмите Enter. Проверьте текст и расписание в списке рядом с
   чатом.

Закрытие главного окна оставляет программу работать в области уведомлений. Чтобы полностью завершить её, выберите
«Выход» в меню колокольчика. Открытые карточки закроются, звук прекратится.

## Локальный CLI

Рядом с `napomni.exe` поставляется консольный клиент `napomni-cli.exe`.
Команда `napomni-cli list` возвращает JSON со всеми сохранёнными напоминаниями,
их стабильными идентификаторами, описаниями расписаний и текущими статусами.
Справка: `napomni-cli --help`. Команда работает без подключения ассистента и интернета.
Команды `create`, `update`, `pause`, `resume`, `delete` принимают JSON одним аргументом
или читают его из стандартного ввода при аргументе `-`. `undo` отменяет последнее
изменение приложения, в том числе сделанное через чат. Полные формы расписаний
описаны в справке; `napomni-cli schema` выводит действительные схемы аргументов.
Если программа закрыта, клиент запускает её в фоне; главное окно остаётся скрытым.
Код завершения 0 означает полученный успешный результат; ошибки выводятся в stderr
с кодом 1. При потере ответа команда не повторяется автоматически.
Ожидание результата ограничено 20 секундами.

В разделе «Настройки» укажите «Папку скиллов» и нажмите «Установить скилл».
По умолчанию используется `%USERPROFILE%\.agents\skills`. Программа создаст
подпапку `napomni` с английской инструкцией и фактическим путём CLI. Установка
в другую папку сохраняет прежнюю копию и соседние скиллы. Результат установки
или ошибка появятся внизу настроек. Интернет для установки не нужен.

Для изолированных проверок `NAPOMNI_DATA_DIR` задаёт отдельную папку данных и область
обнаружения экземпляра. `NAPOMNI_APP_EXE` позволяет явно задать путь основного приложения;
по умолчанию клиент ищет `napomni.exe` рядом с собой.

## Подключение ассистента

Ассистент понимает сообщения и превращает их в напоминания. Для него нужен доступ к сервису ИИ: адрес подключения,
API-ключ и модель. Эти данные предоставляет выбранный сервис с OpenAI-совместимым API и поддержкой инструментов (tool
calling).

В разделе «Настройки»:

1. Вставьте адрес сервиса в поле «Базовый URL» и свой ключ в поле «API-ключ».
2. Нажмите «Выбрать…» рядом с полем «Модель». Найдите модель по названию или укажите её ID вручную, если список
   недоступен.
3. Нажмите «Проверить» и дождитесь результата.

Интернет нужен для общения с внешним сервисом. Если связь пропадёт, сохранённые расписания продолжат работать.
Приостановить, возобновить или удалить запись кнопками в списке тоже можно без ассистента.

## Что написать в чате

| Задача                              | Пример сообщения                                                                                         |
|-------------------------------------|----------------------------------------------------------------------------------------------------------|
| Напомнить через некоторое время     | Напомни выпить воды через 20 минут                                                                       |
| Напомнить завтра                    | Напомни завтра в 10:00 позвонить врачу                                                                   |
| Повторять через равные промежутки   | Напоминай размяться каждые полчаса                                                                       |
| Ограничить повторы рабочим временем | Напоминай размяться каждые полчаса с 09:00 до 18:00 по будням                                            |
| Выбрать несколько дней и времён     | Напоминай полить цветы по вторникам и субботам в 09:00 и 19:00                                           |
| Повторять раз в две недели          | Напоминай проверить задачи каждые две недели по вторникам в 10:00, начиная с недели 19 октября 2026 года |
| Повторять каждый месяц              | Каждый месяц 15-го в 12:00 напомни оплатить интернет                                                     |
| Повторять каждый год                | Каждый год 10 мая в 09:00 напомни поздравить друга                                                       |

В сообщении можно задать период действия, исключить отдельные даты, выбрать цвет рамки и включить или выключить звук.
Например: «Напомни через 10 минут проверить духовку, со звуком и красной рамкой».

Если для расписания не хватает данных, ассистент задаст уточняющий вопрос. После создания проверьте запись в списке: там
видны сохранённое расписание и настройка звука.

Чтобы отсчитывать интервал от закрытия карточки, напишите: «Напоминай размяться через 10 минут после каждого закрытия уведомления».
В списке появится «Через 10 мин после закрытия», а пока карточка открыта — «Ожидает закрытия уведомления».
Первое уведомление появится через указанный интервал после создания. Обычное «каждые 10 минут» сохраняет фиксированное расписание.
При каждом запуске программы все интервалы «после закрытия» начинаются заново на полный срок; старые отложения этих
напоминаний отменяются. Выход из сна не считается запуском: открытая карточка продолжает ждать закрытия, отложенная —
повторного показа. Если во время сна пропущено обычное срабатывание этого режима, начинается полный интервал заново.

## Как изменить напоминание

Найдите запись в списке. Фильтры «Активные», «На паузе» и «Завершённые» помогают отделить текущие дела от остальных.

- **Изменить:** нажмите «Изменить» у записи, затем напишите в чат, что поменять. Например: «Перенеси на 18:30» или
  «Выключи звук».
- **Приостановить:** нажмите «На паузу». Чтобы снова получать напоминания, нажмите «Возобновить».
- **Удалить:** нажмите значок удаления у записи и подтвердите действие.
- **Отменить изменение:** нажмите кнопку «Отменить последнее изменение» над списком.

Удаление, пауза или изменение записи не закрывают уже появившуюся карточку. Её текст, цвет и звук остаются прежними до
закрытия. Отмена изменения тоже не возвращает закрытые карточки.

Если связь оборвалась во время ответа, сначала проверьте список: ассистент мог уже сохранить изменения. Кнопка
«Продолжить ответ» позволяет продолжить прерванный ответ без повторного выполнения сохранённых операций. Она доступна и
после перезапуска программы.

## Карточки и звук

Несколько карточек собираются в стопку. Наведите на неё указатель, чтобы раскрыть, и прокрутите колесом мыши, чтобы
увидеть остальные карточки или длинный текст. Для закрытия нажмите крестик или перетащите карточку вбок.

Кнопка «Отложить» скрывает карточку и повторно показывает её через 5 минут. Длительность можно изменить в «Настройках»,
в поле «Откладывать на, мин». При отложении звук этой карточки прекращается; при повторном показе он включается снова,
если был включён у исходной карточки. Отложения сохраняются при перезапуске, кроме расписаний «после закрытия»: для них
каждый запуск начинает полный интервал заново.

Для расписания «после закрытия» отложение не запускает новый интервал: он начнётся только после закрытия повторно
показанной карточки. Обычное расписание сохраняет свои сроки. Если очередное срабатывание наступит раньше отложенного
показа или одновременно с ним, отложенный показ отменится. Пауза или удаление напоминания также отменяют отложенный показ.

Звуковой сигнал повторяется, пока открыта хотя бы одна карточка со звуком. Закройте все такие карточки, чтобы остановить
сигнал. Беззвучные карточки можно оставить на экране.

В «Настройках» нажмите «Размещение тостов», чтобы выбрать монитор и угол экрана. Тостами в интерфейсе называются
всплывающие карточки. По умолчанию они появляются справа вверху основного монитора. Кнопка «Тест тостов» показывает три
беззвучные карточки для проверки размещения.

Светлая или тёмная тема выбирается по настройкам Windows.

## Автозапуск

Включите «Автозапуск при входе в Windows» в разделе «Настройки», чтобы программа запускалась после входа в вашу учётную
запись.

Если перенесли программу в другую папку, запустите её оттуда и выключите, затем снова включите автозапуск.

## Как учитывается время

- Время вроде «завтра в 10:00» следует местному времени Windows. Задержка вроде «через 20 минут» отсчитывается от
  отправки сообщения.
- Будни означают понедельник–пятницу, без учёта праздничных дней.
- Если в месяце нет нужного числа, срабатывание пропускается. Например, напоминание на 31-е не появится в апреле, а на
  29 февраля сработает только в високосный год.
- Программа не будит компьютер. Напоминания, пропущенные во время сна или пока программа была закрыта, не показываются
  после возвращения.
- Открытые карточки после перезапуска не восстанавливаются. У одного напоминания одновременно бывает только одна
  карточка.
- Промежуток времени через полночь, например с 22:00 до 06:00, пока не поддерживается.

## Если что-то не работает

**Нет напоминания.** Проверьте, запущена ли программа, активна ли запись и правильно ли указано время в Windows. Для
проверки показа карточек нажмите «Тест тостов» в настройках.

**Нет звука.** Проверьте настройку звука у напоминания, громкость Windows и выбранное устройство вывода. Тестовые
карточки всегда беззвучны.

**Ассистент не отвечает.** Проверьте подключение кнопкой «Проверить». Уточните адрес сервиса, ключ и модель. Модель
должна поддерживать инструменты, а сервис должен быть доступен.

## Данные

Напоминания, настройки и история чата сохраняются на компьютере. Историю можно удалить кнопкой «Очистить историю» в
чате.

При работе чата выбранный сервис ИИ получает историю переписки и данные напоминаний, которые ассистент запрашивает для
выполнения команды. API-ключ хранится локально открытым текстом, хотя в окне скрыт.

Инструкции для разработчиков находятся в [DEV.md](DEV.md).
