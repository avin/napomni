# Встроенные ресурсы

`app.svg` — векторный исходник синего колокольчика с цветом `#6997ff`. Из него со сглаживанием создаётся `app.ico` с кадрами 16, 20, 24, 32, 40, 48, 64, 96, 128 и 256 пикселей. `app.rc` встраивает ICO как ресурс № 1: его используют трей, окно и Проводник Windows. Для заголовка и панели задач окно загружает отдельные размеры с учётом DPI.

Пересоздать ICO через ImageMagick из корня проекта:

```powershell
magick -background none -density 3072 assets/app.svg -define icon:auto-resize=256,128,96,64,48,40,32,24,20,16 assets/app.ico
```

## Сигнал

`reminder.wav` создан для этого приложения: PCM, mono,16kHz,16bit,2секунды. Два синусоидальных затухающих тона660/880Hz и пауза образуют один повторяемый сигнал. Файл встраивается в исполняемый файл; внешние аудиофайлы и пользовательские пути не нужны.
