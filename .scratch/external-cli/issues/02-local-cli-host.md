# 02: CLI — общий список и фоновый запуск приложения

**What to build:** Внешний агент запускает отдельный консольный клиент и получает общий список напоминаний. Клиент подключается к работающему приложению либо запускает его в фоне, передаёт команду, получает результат и завершается. Основное приложение остаётся единственным владельцем данных и планировщика; установленная программа уже содержит оба исполняемых файла.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Поставляются основное GUI-приложение и отдельный консольный CLI-клиент. Обычный запуск, трей и открытие главного окна сохраняют привычное поведение.
- [ ] Команда списка возвращает фактические сохранённые напоминания, стабильные идентификаторы, описания расписаний и текущие статусы, включая записи внутреннего чата.
- [ ] Клиент использует локальный канал в контексте текущего пользователя Windows на том же компьютере. Для внешней команды не требуются провайдер, модель, API-ключ или интернет.
- [ ] Если приложение работает, клиент передаёт команду ему. Если оно закрыто, клиент запускает его в фоне, дожидается готовности и получает результат без открытия или активации главного окна.
- [ ] Одновременные холодные запуски клиентов приводят к одному владельцу состояния и одному планировщику. Повторный обычный запуск приложения также не создаёт независимого писателя в общее хранилище.
- [ ] CLI не загружает отдельное изменяемое состояние напоминаний и не запускает собственный планировщик. Прикладной обработчик работает с тем же ядром, которым пользуются чат и интерфейс.
- [ ] Успешное завершение клиента следует после результата команды. Ошибка запуска, недоступность приложения и неверная команда дают ошибочное завершение и доступную диагностику без ложного успеха и бесконечного ожидания.
- [ ] Действительная справка CLI описывает доступную команду списка и её результат. Конкретные синтаксис и транспорт выбираются в рамках согласованной спецификации.
- [ ] Существующая сборка и установщик включают оба исполняемых файла; установленный клиент находит установленное основное приложение, в том числе в каталоге с пробелами. Дополнительная галочка установки скилла не появляется.
- [ ] Сквозные проверки запускают настоящий CLI с изолированными данными и обнаружением тестового экземпляра: работающий экземпляр, холодный запуск, несколько одновременных клиентов, неверная команда и ошибка запуска. Пользовательский экземпляр приложения не затрагивается.
- [ ] На Windows подтверждены фоновый запуск без активации главного окна и получение списка из установленной поставки. Поведение можно продемонстрировать независимо от команд изменения и разового показа.
