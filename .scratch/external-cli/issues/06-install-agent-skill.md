# 06: Установка английского скилла из настроек

**What to build:** Пользователь открывает настройки, видит подставленную персональную папку скиллов и устанавливает один комплектный английский скилл кнопкой. Он может заменить путь и повторить установку в другое место. Агент по установленной инструкции использует фактический CLI для немедленного показа и полного управления напоминаниями.

**Blocked by:** 03 — Немедленный показ разового уведомления через CLI; 04 — Полное управление напоминаниями через CLI.

**Status:** claimed

- [ ] В настройках доступны редактируемое поле «Папка скиллов» и кнопка «Установить скилл». Исходный путь — стандартный персональный каталог скиллов текущего пользователя, зафиксированный спецификацией.
- [ ] По кнопке один комплектный скилл устанавливается в собственную подпапку выбранного корня с корректным SKILL.md. Его инструкции написаны на английском языке.
- [ ] Скилл охватывает оба согласованных сценария: немедленный показ разового уведомления только по тексту и все реализованные операции управления напоминаниями. Инструкции и примеры соответствуют действительным справке, аргументам и результатам CLI.
- [ ] Инструкция объясняет различие разового уведомления и напоминания с расписанием, простой результат разового показа и отдельную карточку на каждый новый вызов. Она не обещает прочтение сообщения или автоматическую дедупликацию.
- [ ] Установленный скилл или его комплектные ресурсы позволяют найти фактический CLI, включая установку программы в нестандартную папку с пробелами. Инструкция не привязана к каталогу разработчика.
- [ ] Пользователь может изменить путь и повторно нажать кнопку для установки в другое место. Прежняя копия и посторонние скиллы остаются на месте; установка не выполняет перенос или удаление старой копии.
- [ ] Успех отображается после установки необходимых файлов. Ошибки пути, создания каталога или записи доступны пользователю и не отображаются как успешная установка.
- [ ] Установка выполняется локально без интернета, скачивания сторонних компонентов, модели и API-ключа.
- [ ] Ресурсы скилла входят в обычную поставку вместе с GUI-приложением и CLI. Новая галочка установщика и автоматическая установка скилла при первом запуске не добавляются.
- [ ] Проверки вызывают публичное действие установки с временными целевыми папками и наблюдают реальные файлы, выбранный корень, фактический путь CLI, сохранение предыдущей копии и соседних скиллов, а также ошибки записи. Они не закрепляют внутреннее дерево GPUI.
- [ ] Скилл проходит проверку формата и практический изолированный сценарий: агент по установленной английской инструкции показывает разовое уведомление и управляет напоминанием через реализованный CLI.
- [ ] В установленной Windows-программе вручную проверены поле пути, нажатие кнопки, результат успешной установки и видимая ошибка неподходящего назначения.
- [ ] Задача не требует завершения отложений из задачи 05: установленный скилл описывает внешний CLI, а отложение выполняется пользовательской кнопкой карточки.
