# 03: Немедленный показ разового уведомления через CLI

**What to build:** Внешний агент или локальный сервис передаёт текст через CLI и сразу получает обычный тост без создания напоминания с расписанием. Карточка отображается в общей стопке, звучит и закрывается как существующие тосты; вызывающая программа получает простой результат выполнения.

**Blocked by:** 01 — Подготовить самостоятельную идентичность тоста; 02 — CLI: общий список и фоновый запуск приложения.

**Status:** ready-for-agent

- [ ] Отдельная команда разового показа принимает только текст. Расписание, отправитель, индивидуальные цвет и звук в её контракт не входят.
- [ ] Переданный текст, включая кириллицу, кавычки и переносы строк, доходит без искажений и отображается существующим способом без добавленного имени отправителя.
- [ ] Карточка использует синюю рамку, включённый повторяющийся звук, текущее размещение тостов и общий путь отрисовки. Показ не перехватывает фокус и не открывает главное окно.
- [ ] Разовые и запланированные тосты находятся в общей стопке. Разовый тост остаётся до ручного закрытия, отложения или полного завершения приложения; автоматического исчезновения нет. Отложение добавляется задачей 05.
- [ ] Каждый отдельный вызов создаёт самостоятельную карточку, даже при одинаковом тексте. Закрытие одной такой карточки не закрывает другую и не затрагивает напоминания.
- [ ] Пока остаётся хотя бы один звучащий тост, общий сигнал продолжается. Закрытие последней звучащей карточки прекращает его.
- [ ] Разовый показ не добавляет запись с расписанием в список, не создаёт скрытого фиктивного напоминания и не изменяет последнюю отменяемую операцию управления напоминаниями.
- [ ] Вызывающая программа получает успех либо ошибку создания карточки без публичного идентификатора разового уведомления, ожидания закрытия и подтверждения прочтения. Само подключение к приложению ещё не считается успехом.
- [ ] Команда работает при закрытом приложении через фоновый запуск из задачи 02. Потеря ответа не вызывает скрытого повторения показа; ошибка получения результата не трактуется как доказательство отсутствия карточки.
- [ ] После полного завершения и повторного запуска приложения уже показанные разовые карточки не восстанавливаются.
- [ ] Прикладные проверки наблюдают состав карточек, неизменность списка и отмены, независимое закрытие и общий сигнал. Сквозной вызов настоящего CLI проверяет передачу текста и результат, а ручная Windows-проверка подтверждает реальную карточку, звук и отсутствие перехвата фокуса.
- [ ] Справка CLI описывает реализованную команду и правило отдельной карточки на каждый вызов; демонстрационные тестовые карточки не используются как её реализация.
