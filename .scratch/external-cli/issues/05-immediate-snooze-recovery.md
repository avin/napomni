# 05: Отложение разовых уведомлений с восстановлением

**What to build:** Пользователь откладывает разовый тост обычной кнопкой карточки, временно прекращает его звук и получает один повторный показ. Отложение сохраняется после выхода из программы и восстанавливается в исходный срок либо сразу при запуске после срока.

**Blocked by:** 03 — Немедленный показ разового уведомления через CLI.

**Status:** ready-for-agent

- [ ] Кнопка отложения разового тоста использует выбранную в настройках длительность, скрывает только выбранную карточку и прекращает её вклад в общий сигнал.
- [ ] Отложение сохраняет снимок текста, рамки и звука и назначает один повторный показ. Напоминание или постоянное расписание при этом не создаются, последняя отменяемая операция управления напоминаниями не меняется.
- [ ] Повторно показанную карточку можно снова отложить; каждое действие назначает один следующий показ без накопления дублей.
- [ ] Несколько одинаковых по тексту разовых уведомлений откладываются и закрываются независимо. Обычные расписания не заменяют отложение разового уведомления.
- [ ] После полного выхода и запуска до срока уведомление остаётся скрытым до первоначального времени. Новый отсчёт от запуска не начинается.
- [ ] При запуске в срок или позже сохранённый тост показывается сразу. Успешно восстановленное отложение не создаёт повторных карточек при последующих опросах и перезапусках.
- [ ] Уже открытая, не отложенная разовая карточка после полного выхода не восстанавливается. Программа различает сохранённое отложение и открытый тост.
- [ ] При повторном показе восстанавливаются исходные содержимое и настройка звука. Общий сигнал учитывает остальные открытые звучащие карточки.
- [ ] Ошибка сохранения отложения оставляет исходную карточку и её звук действующими. Сбой фиксации повторного показа не теряет сохранённое отложение и позволяет продолжить без дубля.
- [ ] Расширенное состояние остаётся совместимым с ранее сохранёнными напоминаниями и обычными отложениями. Прежние правила расписаний, включая интервал после закрытия, не меняются.
- [ ] Проверки управляемого времени и настоящего временного хранилища воспроизводят запуск до срока, в срок и после срока, повторное отложение, несколько карточек и ошибки записи без ожидания реальных минут.
- [ ] Сквозной сценарий начинается с карточки из настоящего CLI, продолжается отложением в интерфейсе и завершается повторным показом после перезапуска; на Windows проверяются фактическое скрытие карточки и остановка её звука.
