# 05: Редактирование, пауза, удаление и отмена

**What to build:** Пользователь выбирает напоминание, меняет его через чат, управляет его состоянием из списка и отменяет последнюю операцию. Изменения данных относятся к будущим срабатываниям и сохраняют уже открытый тост.

**Blocked by:** 04 — Первое напоминание: от команды до тоста.

**Status:** ready-for-agent

- [ ] Кнопка «Редактировать» явно прикрепляет выбранную запись к следующей команде. Записи с одинаковым текстом различаются устойчивыми идентификаторами.
- [ ] Через чат меняются текст, время, цвет рамки и настройка звука; изменяются только явно запрошенные свойства.
- [ ] Чат сообщает фактический результат изменения; при неоднозначности изменение не выполняется до уточнения.
- [ ] Кнопки «Приостановить/Возобновить» прекращают и возобновляют будущие срабатывания; «Удалить» убирает запись из списка и прекращает будущие срабатывания.
- [ ] Состояние и изменения записей сохраняются между запусками.
- [ ] Редактирование, пауза и удаление не меняют текст, рамку и настройку звука открытого тоста и не закрывают его.
- [ ] Действие «Отменить» отменяет последнюю операцию создания, редактирования, удаления или изменения состояния; отмена удаления возвращает запись и её будущие срабатывания.
- [ ] Отмена данных не восстанавливает закрытые тосты и не превращает пропущенные срабатывания в немедленные уведомления.
- [ ] Нет форм редактирования свойств напоминания; обычные кнопки управления списком остаются доступны.
- [ ] Проверки через прикладные операции покрывают точечное изменение с сохранением остальных свойств, выбранный ID, паузу, удаление, отмену и неизменность открытого тоста. Эти операции используются и инструментами LLM, и кнопками интерфейса.
