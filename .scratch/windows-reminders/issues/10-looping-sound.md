# 10: Звук до закрытия тостов

**What to build:** Показ напоминания со звуком включает повторяющийся встроенный сигнал; один общий сигнал сопровождает все звучащие тосты и прекращается после закрытия последнего из них.

**Blocked by:** 05 — Редактирование, пауза, удаление и отмена.

**Status:** ready-for-agent

- [ ] В первой версии используется один встроенный звук; создание напоминания без явного указания звука по умолчанию включает его.
- [ ] Команды чата включают и выключают звук конкретной записи, настройка сохраняется и относится к будущим тостам.
- [ ] Показ звучащего тоста включает повтор до его закрытия; беззвучный тост не включает сигнал.
- [ ] Несколько звучащих тостов используют один общий сигнал без наложения отдельных воспроизведений.
- [ ] Закрытие одного звучащего тоста сохраняет сигнал, пока открыт другой; закрытие последнего прекращает сигнал, даже если остались беззвучные карточки.
- [ ] Изменение, пауза и удаление записи не меняют звуковой снимок открытого тоста: уже звучащий продолжает звучать, уже беззвучный не начинает звучать.
- [ ] Закрытие главного окна не прекращает сигнал открытых тостов; полное завершение приложения прекращает звук и закрывает карточки.
- [ ] В карточке нет отдельной кнопки выключения звука, откладывания или редактирования.
- [ ] Прикладные тесты проверяют состояние общего сигнала с несколькими карточками и снимками свойств; реальный повтор и остановка воспроизведения проверены на Windows.
