# 10: Звук до закрытия тостов

**What to build:** Показ напоминания со звуком включает повторяющийся встроенный сигнал; один общий сигнал сопровождает все звучащие тосты и прекращается после закрытия последнего из них.

**Blocked by:** 05 — Редактирование, пауза, удаление и отмена.

**Status:** resolved

- [x] В первой версии используется один встроенный звук; создание напоминания без явного указания звука по умолчанию включает его.
- [x] Команды чата включают и выключают звук конкретной записи, настройка сохраняется и относится к будущим тостам.
- [x] Показ звучащего тоста включает повтор до его закрытия; беззвучный тост не включает сигнал.
- [x] Несколько звучащих тостов используют один общий сигнал без наложения отдельных воспроизведений.
- [x] Закрытие одного звучащего тоста сохраняет сигнал, пока открыт другой; закрытие последнего прекращает сигнал, даже если остались беззвучные карточки.
- [x] Изменение, пауза и удаление записи не меняют звуковой снимок открытого тоста: уже звучащий продолжает звучать, уже беззвучный не начинает звучать.
- [x] Закрытие главного окна не прекращает сигнал открытых тостов; полное завершение приложения прекращает звук и закрывает карточки.
- [x] В карточке нет отдельной кнопки выключения звука, откладывания или редактирования.
- [x] Прикладные тесты проверяют состояние общего сигнала с несколькими карточками и снимками свойств; реальный повтор и остановка воспроизведения проверены на Windows.


## Answer

Реализован один встроенный WinMM-сигнал с асинхронным циклом для агрегированного состояния звуковых снимков. Закрытие последнего звучащего тоста и выход явно останавливают воспроизведение; изменения записи не меняют текущий снимок. Две прикладные проверки пройдены. Отдельно выполнен настоящий запуск/цикл/остановка через Windows API; слышимость физического устройства не проверялась. Подробности: [10-looping-sound.md](../../../docs/verification/10-looping-sound.md).
