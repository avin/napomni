# 07: Дни недели и циклы каждые N недель

**What to build:** Пользователь задаёт выбранные дни недели, несколько времён в день и циклы каждые N недель; сохранённое календарное расписание приводит к тостам по местному времени Windows.

**Blocked by:** 04 — Первое напоминание: от команды до тоста.

**Status:** ready-for-agent

- [ ] Через чат создаётся календарный повтор по одному или нескольким дням недели и нескольким временам в день; список и чат показывают понятное описание.
- [ ] Поддерживается «раз в две недели по вторникам и четвергам» и общий цикл каждые N недель с положительным N.
- [ ] Неделя начинается в понедельник; выбранные дни принадлежат активной неделе, остальные недели цикла пропускаются. Если начальная неделя не названа, LLM уточняет её до создания.
- [ ] Календарные часы следуют местному времени Windows после смены часового пояса, а не фиксированному UTC-времени.
- [ ] Перевод часов назад не даёт второго срабатывания для повторившегося местного времени; отсутствующее время при переводе вперёд пропускается.
- [ ] Расписание и фаза недельного цикла сохраняются после перезапуска; пропущенные срабатывания не догоняются.
- [ ] Во всех календарных повторах открыт максимум один тост записи, а закрытие тоста не прекращает её расписание.
- [ ] Управляемое время проверяет границу недели и года, фазу двухнедельного цикла, несколько времён, смену пояса и перевод часов. Сквозной сценарий проходит через чат, сохранённый список и показ тоста.
