# 07: Дни недели и циклы каждые N недель

**What to build:** Пользователь задаёт выбранные дни недели, несколько времён в день и циклы каждые N недель; сохранённое календарное расписание приводит к тостам по местному времени Windows.

**Blocked by:** 04 — Первое напоминание: от команды до тоста.

**Status:** resolved

- [x] Через чат создаётся календарный повтор по одному или нескольким дням недели и нескольким временам в день; список и чат показывают понятное описание.
- [x] Поддерживается «раз в две недели по вторникам и четвергам» и общий цикл каждые N недель с положительным N.
- [x] Неделя начинается в понедельник; выбранные дни принадлежат активной неделе, остальные недели цикла пропускаются. Если начальная неделя не названа, LLM уточняет её до создания.
- [x] Календарные часы следуют местному времени Windows после смены часового пояса, а не фиксированному UTC-времени.
- [x] Перевод часов назад не даёт второго срабатывания для повторившегося местного времени; отсутствующее время при переводе вперёд пропускается.
- [x] Расписание и фаза недельного цикла сохраняются после перезапуска; пропущенные срабатывания не догоняются.
- [x] Во всех календарных повторах открыт максимум один тост записи, а закрытие тоста не прекращает её расписание.
- [x] Управляемое время проверяет границу недели и года, фазу двухнедельного цикла, несколько времён, смену пояса и перевод часов. Сквозной сценарий проходит через чат, сохранённый список и показ тоста.

## Answer

Реализовано недельное календарное расписание: выбранные дни 1–7 (понедельник–воскресенье), несколько местных времён, положительное N недель и сохранённая дата понедельника первой активной недели. Для N>1 отсутствие начальной недели возвращает уточнение без сохранения; начальная дата не подменяется произвольно. Список и фактический ответ инструмента показывают дни, времена, период и фазу. Схема и системное сообщение LLM описывают weekly и обязательное уточнение фазы.

Календарная арифметика идёт по местным датам, разрешение местного времени — через заменяемые часы Windows. Не существующее время пропускается, повторившееся разрешается только в первый UTC-момент. Сохранённый календарный курсор дополнительно предотвращает повтор при ручном переводе часов назад и перезапуске; он общий для будущих месячных/годовых правил.

Проверки через согласованные публичные операции приложения: дни и несколько времён; закрытие не прекращает повтор; сохранность открытого снимка при следующем срабатывании; двухнедельная фаза, граница года, пропущенные срабатывания при перезапуске; отрицательные правила без записи; смена пояса; весенний пропуск; два времени осеннего повтора и перезапуск; ручной откат часов через оба сработавших времени. HTTP-стенд проверяет объявление weekly провайдеру, вызов инструмента, фактическое описание, сохранённый список и последующий офлайн-тост. Реальная LLM и визуальная Windows-проверка этим набором не заявляются.
