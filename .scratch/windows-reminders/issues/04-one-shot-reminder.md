# 04: Первое напоминание — от команды до тоста

**What to build:** Пользователь создаёт однократное напоминание через чат, видит сохранённую запись, получает тост в назначенное время и видит завершённую запись после срабатывания. Сохранённое расписание исполняется локально без LLM.

**Blocked by:** 02 — Подключение LLM и общий чат. Каталог моделей из задачи 03 не требуется: доступен ручной ID.

**Status:** resolved

- [x] Команда на русском создаёт запись только через вызов инструмента; обычный текст ответа сам по себе не изменяет данные.
- [x] Запись имеет устойчивый идентификатор, текст, однократное расписание, цвет рамки и настройку звука; по умолчанию рамка синяя, звук включён. Реальное воспроизведение звука добавляется задачей 10.
- [x] Приложение проверяет аргументы до сохранения; неоднозначные или неполные команды требуют уточнения, а неподдерживаемые правила не заменяются приблизительными.
- [x] Работают конкретная дата и время и относительное начало «через 20 минут». Относительное время и дата для слова «завтра» вычисляются от отправки команды.
- [x] Если целевое время уже прошло до применения, приложение просит уточнить время вместо немедленного показа.
- [x] Текст в кавычках сохраняется дословно; без кавычек LLM извлекает текст из команды. Результат в чате содержит фактически сохранённый текст и понятное расписание.
- [x] Сохранённые напоминания видны в полном списке и переживают перезапуск; сохранённая запись исполняется без интернета и запросов к модели.
- [x] В назначенное время открывается тост со снимком свойств записи; автозакрытия нет. Однократная запись попадает в раздел «Завершённые».
- [x] Завершение приложения закрывает тост; перезапуск его не восстанавливает. Пропущенное время выключения, сна и остановки не вызывает догоняющий показ; компьютер не пробуждается.
- [x] Через общие прикладные операции с управляемым временем проверены создание, сохранение, срабатывание, завершение и пропуск; LLM-граница проверяется локальным HTTP-стендом.


## Answer

Реализованы публичное ядро с управляемыми часами и хранилищем, однократные местные/относительные расписания, проверяемые LLM-инструменты, сохранённый список и настоящие тосты со снимками. Отправка команды фиксирует время; сон и перезапуск не догоняют пропуски. Фактическое создание видно независимо от заключительного ответа API. Проверки и граница Windows-приёмки: [04-one-shot-reminder.md](../../../docs/verification/04-one-shot-reminder.md).
