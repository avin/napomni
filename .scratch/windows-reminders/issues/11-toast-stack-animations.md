# 11: Стопка и анимации в стиле Base UI

**What to build:** Настоящие тосты напоминаний образуют компактную анимированную стопку в стиле основного stacked-toast примера Base UI и остаются доступны до ручного закрытия независимо от количества карточек.

**Blocked by:** 04 — Первое напоминание: от команды до тоста.

**Status:** claimed

- [ ] Новая карточка плавно появляется впереди; задние карточки уменьшены и смещены, их содержимое не мешает чтению передней.
- [ ] Наведение или фокус раскрывают стопку для чтения отдельных карточек; при уходе взаимодействия возвращается компактное представление.
- [ ] Закрытие отдельной карточки плавно перестраивает стопку, сохраняя остальные открытые тосты и их порядок.
- [ ] Жест перетаскивания для удаления равнозначен кнопке закрытия. В карточке доступны текст, цветная рамка и закрытие, без дополнительных действий.
- [ ] При нехватке высоты раскрытая стопка прокручивается; карточки не отбрасываются из-за переполнения и каждую можно прочитать и закрыть.
- [ ] Уведомление с длинной кириллицей корректно переносится и остаётся читаемым; карточки разной высоты не ломают раскрытие и закрытие.
- [ ] Автозакрытия нет; повторное срабатывание уже открытой записи не создаёт дубль, не переставляет её и не повторяет анимацию.
- [ ] Появление и перестроение не отнимают фокус у другого приложения. Цвет рамки и тема сохраняются при анимациях.
- [ ] Визуально проверены свёрнутая и раскрытая стопка, переполнение, жест закрытия и масштабирование Windows; прикладные проверки подтверждают сохранность незакрытых карточек и корректное закрытие выбранного тоста.
