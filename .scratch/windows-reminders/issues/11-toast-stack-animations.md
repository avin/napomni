# 11: Стопка и анимации в стиле Base UI

**What to build:** Настоящие тосты напоминаний образуют компактную анимированную стопку в стиле основного stacked-toast примера Base UI и остаются доступны до ручного закрытия независимо от количества карточек.

**Blocked by:** 04 — Первое напоминание: от команды до тоста.

**Status:** resolved

- [x] Новая карточка плавно появляется впереди; задние карточки уменьшены и смещены, их содержимое не мешает чтению передней.
- [x] Наведение или фокус раскрывают стопку для чтения отдельных карточек; при уходе взаимодействия возвращается компактное представление.
- [x] Закрытие отдельной карточки плавно перестраивает стопку, сохраняя остальные открытые тосты и их порядок.
- [x] Жест перетаскивания для удаления равнозначен кнопке закрытия. В карточке доступны текст, цветная рамка и закрытие, без дополнительных действий.
- [x] При нехватке высоты раскрытая стопка прокручивается; карточки не отбрасываются из-за переполнения и каждую можно прочитать и закрыть.
- [x] Уведомление с длинной кириллицей корректно переносится и остаётся читаемым; карточки разной высоты не ломают раскрытие и закрытие.
- [x] Автозакрытия нет; повторное срабатывание уже открытой записи не создаёт дубль, не переставляет её и не повторяет анимацию.
- [x] Появление и перестроение не отнимают фокус у другого приложения. Цвет рамки и тема сохраняются при анимациях.
- [ ] Визуально проверены свёрнутая и раскрытая стопка, переполнение, жест закрытия и масштабирование Windows; прикладные проверки подтверждают сохранность незакрытых карточек и корректное закрытие выбранного тоста.

## Answer

Реализована единая GPUI-стопка для настоящих и тестовых тостов: компактные уменьшенные задние карточки со скрытым содержимым; новые впереди; плавное появление/перестроение; раскрытие наведением или явным клавиатурным входом из трея; колесо и клавиши прокручивают все карточки, включая длинную кириллицу. Закрытие кнопкой или горизонтальным жестом вызывает одну прикладную операцию; исходные ID/sequence снимков сохраняют порядок и не перезапускают анимацию при дублях. Отсутствует отбрасывание по высоте. Нативный регион исключает пустые пиксели, окно остаётся квадратным и не активируется при срабатывании. Удаление popup также закрывает его снимки ядра, чтобы не оставлять невидимый звучащий тост. Сохранены хуки общего сигнала задачи 10.

Проверки и точные ограничения: [11-toast-stack.md](../../../docs/verification/11-toast-stack.md). 50 автоматических проверок прошли, сборка и форматирование прошли; настоящий изолированный Windows-запуск подтвердил живой popup, непустой сложный регион компактных карточек и неизменный foreground HWND. Визуальная приёмка не заявляется: ранее захват GPUI через Computer Use дважды завершился тайм-аутом. Последний чекбокс остаётся открытым для ручной проверки.
