# 08: Ежемесячные и ежегодные напоминания

**What to build:** Пользователь задаёт числа месяца и ежегодные даты через чат и получает тосты в допустимые календарные даты без автоматического переноса несуществующих дат.

**Blocked by:** 04 — Первое напоминание: от команды до тоста.

**Status:** ready-for-agent

- [ ] Через чат создаются ежемесячные напоминания по выбранным числам и ежегодные напоминания по дате и времени.
- [ ] Расписание сохраняется, отображается в списке и понятно пересказывается в результате чата.
- [ ] Правило на 31-е пропускает месяцы без 31-го, не переносится на последний день и продолжает работать в следующем подходящем месяце.
- [ ] Ежегодное 29 февраля срабатывает только в високосный год; невозможные конкретные даты не сохраняются как другое число.
- [ ] Правила следуют местному времени Windows и общим ограничениям: повторившееся местное время не даёт второй показ, отсутствующее время пропускается.
- [ ] Перезапуск сохраняет расписание, но не восстанавливает тосты и не догоняет пропущенные даты.
- [ ] Открытый тост записи исключает создание дубля при следующем срабатывании.
- [ ] Прикладные проверки с управляемым временем покрывают короткие месяцы, переход года, високосный и невисокосный годы, пропуски и сохранение записи. Есть воспроизводимый сценарий от команды до тоста.
