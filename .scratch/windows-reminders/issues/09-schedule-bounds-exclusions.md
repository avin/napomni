# 09: Периоды, окна часов и исключения

**What to build:** Пользователь ограничивает поддерживаемые повторы периодом дат, часами, днями и исключениями, сохраняя единое понятное расписание и получая тосты только в разрешённые моменты.

**Blocked by:** 06 — Интервальные напоминания; 07 — Дни недели и циклы каждые N недель; 08 — Ежемесячные и ежегодные напоминания.

**Status:** resolved

- [x] Через чат задаются начальная и конечная даты повторения, окна времени и исключения конкретных дат; ограничения сохраняются с записью.
- [x] Сквозной сценарий «каждые полчаса с 09:00 до 18:00 по будням, кроме выбранной даты» создаётся инструментом, виден в списке и показывает тосты только в разрешённые моменты.
- [x] «Будни» означают понедельник–пятницу без внешнего календаря праздников.
- [x] Ограничения применяются согласованно к интервальным, недельным, месячным и ежегодным правилам там, где соответствующая комбинация поддерживается; неподдерживаемые комбинации объясняются без приблизительной подмены.
- [x] Исключённая дата не переносит срабатывание на другой день и не меняет фазу повторения.
- [x] Границы дат и окон имеют однозначное описание в результате команды; проверки включают моменты до начала, на границах и после конца.
- [x] После завершения периода расписание не создаёт новые тосты; уже открытая карточка остаётся до явного закрытия.
- [x] Управляемое время покрывает комбинации ограничений, исключённую дату, выходные, переход месяца и восстановление сохранённого расписания после перезапуска.

## Answer

Добавлено общее constrained-правило с включительными местными границами дат/часов, днями недели и исключениями. Фильтрация сохраняет фазу interval/weekly/monthly/yearly. patch.limits меняет или снимает ограничения без повторного создания базовой сетки; отмена и открытые снимки сохраняют прежнее поведение.

Полчаса09–18 по будням с исключением, широкий интервал, границы, завершение периода, перезапуск и календарные комбинации проверены пятью прикладными тестами и HTTP-сценарием. Неподдерживаемые сочетания не приближаются: поиск ограничен400 календарными годами/100000 кандидатами и даёт явную ошибку; ночные окна и вложенность также отклоняются. Полный набор, fmt и clippy прошли. Подробности — [протокол](../../../docs/verification/09-constraints.md); визуальная приёмка нового сценария остаётся отдельной.
