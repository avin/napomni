# 01: GPUI — трей, окно и тестовые тосты

**What to build:** Запускаемое нативное Windows-приложение на Rust и GPUI, позволяющее проверить трей, главное окно и показ тестовых тостов до построения планировщика и подключения LLM. Основной результат — подтверждённая пригодность выбранного UI для чёткого русского текста и окон без захвата фокуса.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Приложение собирается и запускается на Windows; интерфейс написан на Rust без веб-технологий, совместимая версия GPUI зафиксирована.
- [ ] Значок находится в трее; двойной щелчок открывает главное окно с русскими подписями и областями будущего списка и чата.
- [ ] Закрытие главного окна оставляет приложение работающим в трее; действие полного завершения останавливает приложение и закрывает его тосты.
- [ ] Воспроизводимый тестовый сценарий показывает несколько карточек с русским текстом и цветной рамкой поверх обычных окон. Карточки остаются до явного закрытия.
- [ ] Само появление тоста не отнимает клавиатурный фокус у другого приложения; закрытие карточки доступно пользователю.
- [ ] Начальное размещение — справа вверху рабочей области основного монитора с учётом панели задач, включая её верхнее положение.
- [ ] Проверены прозрачность вне карточек, скругления и взаимодействие мышью с видимыми карточками и окружающими окнами.
- [ ] Интерфейс следует светлой или тёмной теме Windows. Кириллица проверена при масштабах 100%, 125% и 150%; результат визуальной проверки чёткости зафиксирован.
- [ ] Зафиксирован воспроизводимый способ запуска и результаты проверки жизненного цикла и фокуса на Windows. При непригодности GPUI причина описана; переход на Tauri не производится автоматически.
