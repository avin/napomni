# 02: Подключение LLM и общий чат

**What to build:** Пользователь задаёт OpenAI-совместимое подключение, проверяет его и ведёт общий русский чат. Для общения используется готовая Rust-библиотека, а не собственная реализация протокола агента.

**Blocked by:** 01 — GPUI: трей, окно и тестовые тосты.

**Status:** ready-for-agent

- [ ] В настройках можно задать базовый URL, API-ключ и вручную ввести ID модели; настройки сохраняются и используются после перезапуска.
- [ ] API-ключ хранится открытым текстом в конфиге по согласованному требованию; ключ не включается в сообщения и сохранённую историю чата.
- [ ] Общение использует готовую Rust-библиотеку: проверена применимость Rig для цикла инструментов и произвольного OpenAI-совместимого URL; при обоснованной несовместимости выбран готовый альтернативный клиент и записана причина.
- [ ] Проверка соединения отличает успешное подключение от ошибки URL, авторизации или модели и проверяет поддержку tool calling без изменения реальных напоминаний.
- [ ] В главном окне есть один общий чат с вводом команды, отображением запроса и ответа; сетевое ожидание не блокирует интерфейс.
- [ ] Поддержка инструментов обязательна у модели и провайдера, но обычный ответ или уточнение не требует принудительного вызова инструмента.
- [ ] История чата сохраняется локально между запусками; пользователь может вручную очистить её.
- [ ] Недоступное подключение даёт понятную ошибку в русском интерфейсе, настройки и история остаются доступны.
- [ ] Проверки с локальным HTTP-стендом покрывают обычный ответ, проверочный вызов инструмента, неверный ключ, несовместимую модель и сетевую ошибку без платных запросов к настоящему провайдеру.
