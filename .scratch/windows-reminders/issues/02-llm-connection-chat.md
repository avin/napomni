# 02: Подключение LLM и общий чат

**What to build:** Пользователь задаёт OpenAI-совместимое подключение, проверяет его и ведёт общий русский чат. Для общения используется готовая Rust-библиотека, а не собственная реализация протокола агента.

**Blocked by:** 01 — GPUI: трей, окно и тестовые тосты.

**Status:** resolved

- [x] В настройках можно задать базовый URL, API-ключ и вручную ввести ID модели; настройки сохраняются и используются после перезапуска.
- [x] API-ключ хранится открытым текстом в конфиге по согласованному требованию; ключ не включается в сообщения и сохранённую историю чата.
- [x] Общение использует готовую Rust-библиотеку: проверена применимость Rig для цикла инструментов и произвольного OpenAI-совместимого URL; при обоснованной несовместимости выбран готовый альтернативный клиент и записана причина.
- [x] Проверка соединения отличает успешное подключение от ошибки URL, авторизации или модели и проверяет поддержку tool calling без изменения реальных напоминаний.
- [x] В главном окне есть один общий чат с вводом команды, отображением запроса и ответа; сетевое ожидание не блокирует интерфейс.
- [x] Поддержка инструментов обязательна у модели и провайдера, но обычный ответ или уточнение не требует принудительного вызова инструмента.
- [x] История чата сохраняется локально между запусками; пользователь может вручную очистить её.
- [x] Недоступное подключение даёт понятную ошибку в русском интерфейсе, настройки и история остаются доступны.
- [x] Проверки с локальным HTTP-стендом покрывают обычный ответ, проверочный вызов инструмента, неверный ключ, несовместимую модель и сетевую ошибку без платных запросов к настоящему провайдеру.

## Answer

Добавлены сохраняемое подключение и общий чат, редактируемые GPUI-поля, асинхронный сетевой обработчик, русские ошибки и ручная очистка истории. Готовый async-openai обслуживает Chat Completions; обоснование выбора вместо Rig и результаты проверок — [протокол](../../../docs/verification/02-llm-chat.md). Публичный Provider::complete возвращает типизированные tool calls для прикладного цикла задачи 04. Проверочный инструмент изолирован от данных напоминаний.

cargo fmt --check, cargo clippy --locked --all-targets -- -D warnings, cargo test --locked прошли; четыре интеграционных теста, без платных запросов. Настоящая визуальная проверка нового интерфейса пока не выполнена.
