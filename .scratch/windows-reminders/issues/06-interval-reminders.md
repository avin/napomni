# 06: Интервальные напоминания

**What to build:** Пользователь создаёт через чат повтор «каждые 10 минут», получает тосты по устойчивой сетке и не получает дубли уже открытой карточки.

**Blocked by:** 04 — Первое напоминание: от команды до тоста.

**Status:** resolved

- [x] Команды задают положительный интервал и при необходимости явное начало; без явного начала сетка привязана к моменту создания.
- [x] Создание в 12:03 с интервалом 10 минут даёт следующие срабатывания в 12:13, 12:23 и далее; расписание понятно описано в списке и результате чата.
- [x] Закрытие тоста, сетевые задержки после создания и перезапуск не сдвигают сетку. Изменение часового пояса не меняет реальную величину интервала.
- [x] Пока тост этого напоминания открыт, повторное срабатывание не создаёт карточку, не меняет порядок и не запускает повторную анимацию.
- [x] Закрытие тоста не создаёт отложенное уведомление пропущенного повтора; следующий срок по сетке снова допускает показ.
- [x] Тосты разных напоминаний с одинаковым текстом не подавляют друг друга.
- [x] Пропуски во время сна, выключения и остановки программы не догоняются. После возвращения ожидается следующий срок; компьютер не пробуждается.
- [x] Запись и исходная привязка интервала сохраняются локально, открытые тосты между запусками не восстанавливаются.
- [x] В интерфейсе по-прежнему нет длительности и автозакрытия: интервал задаёт только моменты будущих срабатываний.
- [x] Управляемое время через прикладные операции проверяет сетку, повтор при открытом тосте, показ после закрытия, пропуски и перезапуск; работающий сценарий доступен через чат и настоящий тост.

## Answer

Добавлены интервальная сетка с сохранённой UTC-привязкой, необязательное явное начало, описание расписания, инструмент чата и проверка аргументов. Повторы открытого тоста не меняют снимок и порядок; закрытие потребляет прошедшие точки только своей записи. Сон и перезапуск пропускают прошлое, а смена часового пояса сохраняет реальную длительность интервала.

Четыре прикладных теста с управляемым временем и HTTP-сценарий прошли вместе с fmt/clippy и полным набором. Подробности — [протокол](../../../docs/verification/06-interval-reminders.md). Новая визуальная проверка настоящего Windows-сценария пока не выполнена.
