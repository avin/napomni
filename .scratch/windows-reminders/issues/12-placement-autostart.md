# 12: Настройки размещения и автозапуск

**What to build:** Пользователь выбирает монитор и угол показа, сохраняет настройки и включает автозапуск Windows. Приложение следует системной теме и размещает карточки в доступной рабочей области.

**Blocked by:** 01 — GPUI: трей, окно и тестовые тосты.

**Status:** resolved

- [x] Настройки позволяют выбрать монитор и угол показа; выбранные значения сохраняются между запусками и применяются к показу тостов.
- [x] По умолчанию выбран правый верхний угол основного монитора.
- [x] Отступы и доступные размеры рассчитываются по рабочей области выбранного монитора, с учётом панели задач сверху, снизу или сбоку там, где такое расположение поддерживается Windows.
- [x] Расчёты учитывают масштаб выбранного монитора; видимые карточки и доступная область стопки не уходят под панель задач или за рабочую область.
- [x] В интерфейсе есть явная настройка автозапуска Windows: включение приводит к запуску приложения при входе пользователя, выключение убирает автозапуск.
- [x] После автозапуска приложение доступно в трее; главное окно открывается двойным щелчком, его закрытие не завершает приложение.
- [x] Светлая и тёмная темы следуют настройке Windows и сохраняют читаемость русского текста и цветной рамки.
- [ ] Геометрия проверена на разных рабочих областях и масштабах; на Windows проверены реальное размещение, сохранение настроек и включение/выключение автозапуска.

## Answer

Реализованы отдельное окно настроек, сохранение выбранного монитора и угла в `%APPDATA%/WinNotifiToast/placement.json`, безопасный возврат на основной монитор при отключении выбранного, физическая рабочая область и масштаб каждого монитора. Тестовые тосты используют публичную геометрию размещения; доступная область стопки предоставлена следующему этапу UI. Автозапуск включается/выключается значением `HKCU/Software/Microsoft/Windows/CurrentVersion/Run/WinNotifiToast` с кавычками вокруг пути exe. Обычный запуск остаётся в трее; текущая светлая/тёмная тема GPUI используется окном настроек и карточками.

Проверено: интеграционные тесты публичного SettingsService (сохранение/повторное открытие; рабочие области с панелью сверху/снизу/сбоку, отрицательные координаты, масштабы 100/125/150%, четыре угла). Отдельно на настоящем Windows выполнен `cargo test --bin win-notifi-toast windows_autostart_roundtrip -- --ignored`: включение, чтение точного пути, выключение, восстановление прежнего значения Run и перечисление настоящих мониторов. Исходное значение автозапуска не изменено после проверки.

Визуальная приёмка размещения, чёткости кириллицы и темы на целевом экране, а также новый вход в Windows для фактического автозапуска остаются ручными проверками общего интегрированного приложения; их выполнение здесь не заявляется. Последний пункт списка отражает эту непроведённую ручную часть.
