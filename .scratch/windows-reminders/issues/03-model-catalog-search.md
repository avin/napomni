# 03: Каталог моделей с поиском

**What to build:** Пользователь загружает каталог своего провайдера и быстро выбирает модель через поиск по части имени или ID, сохраняя возможность ручного ввода.

**Blocked by:** 02 — Подключение LLM и общий чат.

**Status:** ready-for-agent

- [ ] Настройки подключения загружают доступный каталог моделей провайдера; размер списка не ограничен заранее заданным числом.
- [ ] Поисковая строка локально фильтрует список по части отображаемого имени и ID без учёта регистра, без сетевого запроса на каждое изменение строки.
- [ ] Выбор из результатов задаёт фактический ID модели, сохраняет его и использует для последующих запросов чата.
- [ ] Для OpenRouter учитываются метаданные поддержки инструментов: заведомо неподходящая модель не предлагается как совместимая.
- [ ] Отсутствие сведений о возможностях не выдаётся за подтверждённую поддержку инструментов; совместимость проверяется механизмом проверки подключения.
- [ ] Недоступный каталог или ошибка загрузки не исключают ручной ввод ID и использование уже сохранённой модели.
- [ ] Проверены пустой поиск, частичное совпадение, разный регистр, отсутствие результатов и выбор из большого фиксированного набора моделей.
- [ ] Локальный HTTP-стенд покрывает каталог OpenRouter, обычный OpenAI-совместимый каталог, отсутствие метаданных и ошибку получения списка.
