# 03: Каталог моделей с поиском

**What to build:** Пользователь загружает каталог своего провайдера и быстро выбирает модель через поиск по части имени или ID, сохраняя возможность ручного ввода.

**Blocked by:** 02 — Подключение LLM и общий чат.

**Status:** resolved

- [x] Настройки подключения загружают доступный каталог моделей провайдера; размер списка не ограничен заранее заданным числом.
- [x] Поисковая строка локально фильтрует список по части отображаемого имени и ID без учёта регистра, без сетевого запроса на каждое изменение строки.
- [x] Выбор из результатов задаёт фактический ID модели, сохраняет его и использует для последующих запросов чата.
- [x] Для OpenRouter учитываются метаданные поддержки инструментов: заведомо неподходящая модель не предлагается как совместимая.
- [x] Отсутствие сведений о возможностях не выдаётся за подтверждённую поддержку инструментов; совместимость проверяется механизмом проверки подключения.
- [x] Недоступный каталог или ошибка загрузки не исключают ручной ввод ID и использование уже сохранённой модели.
- [x] Проверены пустой поиск, частичное совпадение, разный регистр, отсутствие результатов и выбор из большого фиксированного набора моделей.
- [x] Локальный HTTP-стенд покрывает каталог OpenRouter, обычный OpenAI-совместимый каталог, отсутствие метаданных и ошибку получения списка.

## Answer

Реализованы загрузка каталога через async-openai, локальный поиск по имени/ID, фильтрация метаданных tools и сохранение выбранного ID. Отдельное GPUI-окно содержит поиск и виртуальный список; ручной ввод остаётся в главном окне. Обычный каталог без метаданных показывает неизвестную совместимость, а модели с явно отсутствующими tools скрыты.

Четыре интеграционных HTTP-теста покрывают большой каталог, поиск, совместимость, недоступность, сохранение и фактический ID следующего запроса чата. Проверки fmt/clippy/test пройдены. Подробности и оставшаяся визуальная приёмка — [протокол](../../../docs/verification/03-model-catalog.md).
