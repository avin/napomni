# Windows reminders — карта реализации

## Notes

Спецификация: [spec.md](spec.md). Интеграционная ветка: `codex/windows-reminders`.
Задача 01 принята пользователем до начала этого прогона.

Граф зависимостей:
- 02 ← 01; 12 ← 01.
- 03 ← 02; 04 ← 02.
- 05, 06, 07, 08, 11 ← 04.
- 09 ← 06, 07, 08.
- 10, 13 ← 05.

Проверки: публичные прикладные операции с управляемым временем и хранилищем; HTTP-стенд на внешней границе LLM. Границы согласованы в Testing Decisions спецификации.

## Decisions-so-far

- [01](issues/01-gpui-tray-toast.md): GPUI, трей и тестовые тосты реализованы и приняты пользователем; исходная точка `2234ae1`.

- [12](issues/12-placement-autostart.md): сохранённые монитор/угол, физическая рабочая область и DPI, отдельное окно настроек, автозапуск HKCU Run. Автоматические геометрические тесты и настоящий Windows Run roundtrip пройдены; визуальная приёмка остаётся отдельной.

- [02](issues/02-llm-connection-chat.md): готовый async-openai, сохраняемый общий чат и подключение, безопасная проверка инструментов, фоновые запросы и редактируемые GPUI-поля; четыре интеграционных проверки HTTP/хранилища.

- [03](issues/03-model-catalog-search.md): каталог через async-openai models.list_byot, локальный поиск без ограничения числа моделей, OpenRouter tools/unknown, сохраняемый выбор и отдельный виртуальный GPUI-список; четыре HTTP-теста.

- [04](issues/04-one-shot-reminder.md): прикладное ядро, однократные напоминания через инструменты, атомарное сохранение, локальное исполнение, список и снимки тостов; 9 новых проверок ядра/HTTP, визуальная Windows-приёмка отмечена отдельно.

- [06](issues/06-interval-reminders.md): постоянная UTC-сетка интервала и фактическое время создания, безопасное закрытие без догоняющего повтора, сохранение фазы при сне/перезапуске/смене зоны, схема и факты инструмента; четыре прикладных теста и HTTP-сценарий.

- [05](issues/05-manage-reminders-undo.md): точечные изменения через чат, выбранный ID и кнопки управления; сохранённая отмена одной операции, неизменность тостов/звука и отсутствие догоняющего показа. Девять новых проверок.
- [07](issues/07-weekly-calendar.md): недельные местные повторы, несколько времён и фаза каждые N недель. Общая календарная политика пропуска отсутствующих времён/первого момента повтора; сохранённый local cursor предотвращает повтор при ручном откате часов и перезапуске. Публичные прикладные проверки и HTTP-стенд пройдены.

- [10](issues/10-looping-sound.md): один встроенный WinMM-цикл по звуковым снимкам, немедленная остановка последнего и при выходе; две прикладные проверки и явно выполненный Windows API-сценарий. Физическая слышимость не подтверждалась.
- [08](issues/08-monthly-yearly-calendar.md): ежемесячные числа и ежегодные даты с несколькими временами, пропуск коротких месяцев/невисокосных лет, общий DST/устойчивый курсор07, сохранение и чат; пять прикладных тестов и HTTP-сценарий.

- [09](issues/09-schedule-bounds-exclusions.md): единые включительные даты/часы, будни и исключения для повторов без сдвига фазы; limits-only изменение/очистка и отмена; пять прикладных тестов и HTTP. Поиск ограничен400 годами/100000 кандидатами, неподдерживаемые сочетания явно отклоняются.
- [11](issues/11-toast-stack-animations.md): единая анимированная GPUI-стопка со скрытыми задними карточками, раскрытием, полной прокруткой, жестом закрытия и явным клавиатурным входом. HWND-регион исключает пустые пиксели; release закрывает снимки ядра. 24-карточный прикладной сценарий и настоящий Windows metadata smoke пройдены; визуальная приёмка остаётся ручной.

- [13](issues/13-llm-clarification-recovery.md): UUID команды, атомарные результаты инструментов и безопасный повтор; сохранённое типизированное продолжение с восстановлением после сбоя, выбранный ID, скрытие ключей и независимый локальный планировщик. Девять новых проверок ядра/HTTP.

## Fog

- Настоящие Windows-проверки новых сценариев выполняются отдельно от автоматизированных тестов; непроверенные результаты отмечаются явно.
