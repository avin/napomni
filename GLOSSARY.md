# Напоминания Windows

Приложение показывает напоминания по расписанию и разовые уведомления. Пользователь управляет напоминаниями через чат; внешние программы могут управлять напоминаниями и запрашивать немедленный показ уведомлений.

## Термины

**Напоминание**:
Сохранённая запись с текстом, расписанием, цветом рамки и настройкой звукового сопровождения.
_Избегать_: Таймер как общее название напоминания.

**Разовое уведомление**:
Сообщение, запрошенное для немедленного показа и не связанное с расписанием напоминания.

**Расписание**:
Правило, определяющее время начала однократного или повторяющегося срабатывания напоминания. Длительность в расписании отсутствует.

**Срабатывание**:
Отдельный случай наступления времени, заданного расписанием напоминания.

**Тост**:
Всплывающая карточка с содержимым напоминания или разового уведомления на момент показа, остающаяся до ручного закрытия, отложения или завершения приложения. У одного напоминания одновременно может быть открыт только один тост; последующие изменения напоминания уже показанный тост не меняют.
_Избегать_: Напоминание как название самой карточки.

**Отложение**:
Временное скрытие тоста с повторным показом через выбранное число минут; отложение не считается закрытием. Для напоминания более раннее или одновременное срабатывание обычного расписания заменяет отложенный показ; для разового уведомления отложение означает один повторный показ без создания расписания.

**Стопка тостов**:
Группа одновременно открытых тостов, визуально собранных вместе.
