# Локальные внешние команды через приложение в трее

Внешние программы на том же Windows-компьютере под тем же пользователем получают интерфейс командной строки со всеми возможностями управления напоминаниями, доступными во внутреннем чате, включая напоминания, созданные через чат. Отдельная команда показывает разовое уведомление без расписания. Команды передаются единственному экземпляру приложения в трее через локальный канал; при отсутствии запущенного экземпляра клиент запускает его в фоне без открытия главного окна.

Поставляются два исполняемых файла: основное приложение с интерфейсом и треем и отдельный консольный CLI-клиент. CLI-клиент передаёт команду основному приложению, получает результат и завершается; собственного состояния напоминаний и планировщика у него нет.

Команда показа разового уведомления принимает только текст, без имени отправителя и дополнительных параметров. Ответ сообщает только об успехе или ошибке создания уведомления; ожидание прочтения или закрытия, выдача идентификатора и отслеживание последующего состояния не требуются.

Каждый вызов показа создаёт отдельное разовое уведомление, даже если текст совпадает с предыдущим. Поиск дублей не выполняется; решение о повторном вызове принимает внешняя программа.

Разовое уведомление использует стандартное оформление обычного напоминания: синюю рамку и включённый звук, повторяющийся до закрытия или отложения звучащих карточек. Тост остаётся до ручного закрытия, отложения или завершения приложения. Отложение вызывает один повторный показ и не создаёт напоминание с расписанием. Уже показанные разовые уведомления после полного завершения и повторного запуска приложения не восстанавливаются.

Отложенное разовое уведомление сохраняет назначенный срок после полного завершения приложения. При запуске до срока оно остаётся скрытым до назначенного времени; при запуске в срок или позже показывается сразу. Новый отсчёт от момента запуска не начинается.

Общий обработчик команд использует ядро приложения, а состояние, планировщик и показ тостов остаются во владении одного экземпляра. Это позволяет использовать приложение из агентов и локальных сервисов, исключая независимых писателей в общий файл напоминаний. Удалённые вызовы в первый вариант интерфейса не входят. Конкретный синтаксис команд и формат локального обмена определяются при реализации в рамках этих решений.

В комплект программы входит один скилл с текстом на английском языке, описывающий работу с CLI: немедленный показ разового уведомления и управление напоминаниями. Установка скилла доступна в настройках программы: редактируемое поле «Папка скиллов» и кнопка «Установить скилл». По умолчанию программа подставляет `%USERPROFILE%\.agents\skills` для текущего пользователя. При нажатии кнопки комплектный скилл устанавливается в собственный каталог с файлом `SKILL.md` внутри выбранной папки. Пользователь может изменить путь и нажать кнопку повторно для установки в другое место; ранее установленная копия при этом не переносится и не удаляется. Программа сообщает об успехе установки или об ошибке. Инструкции скилла должны учитывать фактический путь установленного CLI, в том числе при выборе нестандартного каталога установки программы.

Установка скилла выполняется по кнопке в настройках, без автоматической установки при первом запуске. Дополнительная галочка или другая опция установки скилла в установщик Inno Setup не добавляется.

Путь персональных скиллов сверён с [официальной документацией OpenAI](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills).
