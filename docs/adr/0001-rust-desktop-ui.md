# Нативный интерфейс на Rust через egui и eframe

Статус: заменено решением [0002 — GPUI и DirectWrite](0002-gpui-directwrite.md).

Приложение и интерфейс реализуем на Rust через egui и eframe без WebView и веб-технологий по требованию пользователя. Base UI служит визуальным и поведенческим ориентиром: карточки, стопку и анимации воссоздаём самостоятельно вместо использования React-компонентов; это сохраняет Rust-стек ценой самостоятельной реализации оформления и поведения окон на Windows.
