# 03: Каталог моделей

Загрузка использует готовый async-openai models.list_byot: расширенный тип ответа сохраняет OpenRouter name и supported_parameters, которые стандартный тип модели отбрасывает. GET выполняется в отдельном потоке с Tokio; поиск фильтрует загруженные записи локально. Количество записей не ограничено. GPUI uniform_list рисует видимые строки, сохраняя доступ к полному результату.

Отсутствие supported_parameters означает неизвестную совместимость. Явный список без tools скрывает модель из выбора. Заявленная поддержка tools не заменяет проверочный вызов перед первым чатом. Ручной ID доступен независимо от каталога. Выбор сохраняет фактический ID в подключении и обновляет поле главного окна.

Проверки: cargo fmt --check, cargo clippy --locked --all-targets -- -D warnings, cargo test --locked. Четыре HTTP-теста каталога без настоящих платных запросов: набор из 2401 модели, поиск по имени/ID/регистру и отсутствие совпадений, метаданные OpenRouter и их отсутствие, недоступность каталога, сохранение выбора и фактический ID в следующем запросе чата. Визуальная приёмка нового окна Windows пока не выполнена.

Источник метаданных: [OpenRouter Models](https://openrouter.ai/docs/guides/overview/models).
