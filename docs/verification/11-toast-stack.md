# 11 — стопка тостов

Реализация: `src/toast_stack.rs`. Один прозрачный GPUI popup содержит все снимки ядра; масштаб и координаты берутся из рабочей области выбранного монитора. Компактно видны передняя карточка и два уменьшенных силуэта, содержимое задних карточек скрывается. Наведение раскрывает стопку, уход сворачивает с небольшой задержкой, чтобы промежутки между карточками не вызывали мерцание. Переходы появления, раскрытия, закрытия и перестроения длятся 220 мс; состояния привязаны к ID и sequence снимка, дубликаты не перезапускают вход.

Развёрнутые карточки имеют высоту по настоящей раскладке DirectWrite/GPUI с переносом русского текста. Колесо прокручивает всю стопку, включая единственную карточку длиннее экрана. Кнопка закрытия удерживается в видимой части длинной карточки. Все снимки остаются в представлении независимо от высоты; ограничение `Placement::card` больше не отбрасывает карточки. Горизонтальный жест за 30% ширины (не более 96 логических пикселей) вызывает ту же операцию закрытия, короткий жест возвращает карточку.

Явный вход с клавиатуры: меню трея «Открыть стопку тостов». Только это пользовательское действие разрешает активацию. Стрелки/Tab выбирают карточку, Enter/Delete/Backspace закрывают выбранную; PageUp/PageDown/Home/End прокручивают; Escape сворачивает. Новые срабатывания не активируют окно. При уходе фокуса вновь включается WS_EX_NOACTIVATE.

Пустые пиксели и промежутки исключаются из HWND через объединение прямоугольных регионов видимых карточек. SetWindowRgn и позиционирование выполняются отложенно, вне обновления GPUI, чтобы синхронные сообщения Windows не входили повторно в App. Скругления отключены; фон вне карточек прозрачен. При Alt+F4 или удалении всего popup его release-hook закрывает оставшиеся снимки ядра через общий путь, сразу освобождая общий звуковой сигнал. Тестовый режим использует тот же renderer, демонстрационные карточки беззвучны и не меняют данные напоминаний.

## Автоматизированные проверки

`cargo test --all-targets`: 50 проверок прошли, две настоящие платформенные проверки намеренно ignored по умолчанию. Дополнительный `tests/toast_stack.rs` проверяет согласованную публичную границу: 24 карточки с длинной кириллицей, сохранность всех снимков/порядка/sequence при повторе, закрытие именно выбранного ID и прекращение сигнала только после звучащей карточки. Это регрессионная проверка уже существующих гарантий ядра, а не автоматизированная проверка пикселей UI. `cargo fmt --check` пройден; приложение собрано на настоящем Windows.

Это подтверждает создание настоящего popup, нативный регион и отсутствие перехвата фокуса при появлении; не заменяет визуальную приёмку. Снимки настоящих GPUI-окон через Computer Use ранее дважды завершились тайм-аутом. Визуальная оценка анимаций, наведения, клика сквозь промежутки, длинной кириллицы, перетаскивания и клавиатурного входа, а также обоих тем и масштабов 100/125/150% остаётся ручной проверкой на целевом экране. Выполнение этих проверок здесь не заявляется.
