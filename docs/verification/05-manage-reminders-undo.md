# 05: Редактирование, пауза, удаление и отмена

Прикладные операции `Application::update`, `set_paused`, `delete`, `undo` используются и инструментами LLM, и кнопками списка. Точечный `ReminderPatch` содержит только названные свойства; проверка выбранного ID не позволяет изменить другую одноимённую запись. Свойства напоминаний редактируются через чат без форм.

Кнопка «Редактировать» прикрепляет устойчивый ID к следующей команде. Выбор остаётся при уточнении или ошибке и снимается после фактической операции либо явного действия «Снять выбор». Кнопки списка дают паузу, возобновление, удаление и отмену. Фактические результаты попадают в общий сохранённый чат.

Отмена сохраняется вместе с данными как одна запись `{id, before, index}`. Счётчик ID не откатывается. Она восстанавливает только затронутую запись и не возвращает закрытые карточки. При том же расписании сохраняется текущий прогресс планировщика, чтобы отмена текста/цвета/звука не повторяла уже обработанные срабатывания.

Данные публикуются после успешной записи. Открытые тосты и их звуковые снимки не участвуют в изменениях. Для изменённого, возобновлённого или восстановленного напоминания граница допустимых срабатываний переносится на фактическое время операции; интервальная сетка остаётся прежней. Это не пропускает наступившее срабатывание другого ID.

Проверки через согласованную прикладную границу:

- Точечное изменение выбранного ID при одинаковых текстах, сохранение остальных свойств и перезапуск.
- Неизменность снимка и общего звука при редактировании, паузе, удалении и отмене.
- Отмена создания, редактирования и паузы; восстановление удаления с прежним ID после перезапуска.
- Пауза/возобновление и поздняя отмена без догоняющего тоста; независимость других записей.
- Неверное изменение не меняет данные и не потребляет отмену; изменение времени сохраняет текст/цвет/звук.
- После интеграции06: возобновление/отмена между точками интервальной сетки не догоняют прошедшую точку и не сдвигают следующую.
- После интеграции07: отмена изменения свойства сохраняет обработанные календарные моменты при откате часов и перезапуске; изменение самого расписания начинает новую границу.
- Изменение времени после ручного отката часов допускает новое будущее время, даже если оно раньше предыдущего срабатывания.
- На границе инструментов: разбор точечного изменения, фактический результат, отказ другого ID и отмена.
