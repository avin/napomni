# 10: Общий повторяющийся звук

`NativeSignal` владеет одним встроенным двухсекундным сигналом. WAV хранится в исполняемом файле в выровненной статической памяти; WinMM `PlaySoundW` запускает его асинхронно с `SND_MEMORY | SND_ASYNC | SND_LOOP | SND_NODEFAULT`. Повтор сохраняется до явной остановки; повторный `reconcile(true)` не создаёт ещё одно воспроизведение и не перезапускает текущее.

Сигнал определяется по `Application::signal_active()` — наличию хотя бы одного открытого звукового снимка. GPUI считывает агрегированное намерение после локального tick и освобождения блокировки ядра. Последний звучащий тост останавливает сигнал непосредственно при закрытии; беззвучные карточки его не удерживают. Ошибка звука не препятствует показу карточек.

Редактирование, пауза, удаление и отмена меняют данные будущих тостов. Старый звуковой снимок остаётся прежним. Закрытие главного окна не останавливает обработчик или плеер. Выход из трея явно закрывает снимки и останавливает звук до `cx.quit`; Drop плеера служит дополнительной остановкой.

Проверки:

- Две новые прикладные проверки через согласованную публичную границу: несколько звучащих ID используют одно агрегированное состояние; закрытие последнего выключает его при оставшейся беззвучной карточке. Изменение, пауза, удаление и отмена сохраняют текущий звуковой снимок; следующий тост использует новое значение; перезапуск не возвращает карточки/звук.
- Тест настоящего Windows API сначала не компилировался без модуля плеера, затем прошёл после его реализации.
- Явно выполнено `cargo test --locked --test sound_windows -- --ignored`:1 успешно. Windows приняла запуск циклического WAV, процесс оставил его работать4,2секунды (больше двух периодов), повторный reconcile не меняет активное намерение, Windows приняла остановку. По умолчанию тест игнорируется, чтобы обычный набор не проигрывал звук.
- Успешный ответ Windows API не доказывает слышимость через физический динамик: системная громкость, устройство вывода и фактическая слышимость отдельно не проверены. Утверждения «слышал звук» нет.
- Обычный набор тестов, `cargo check --locked` и `cargo fmt --check` пройдены.

Основание API: [Microsoft PlaySound](https://learn.microsoft.com/en-us/previous-versions/dd743680(v=vs.85)) документирует асинхронный цикл, остановку нулевым указателем и требование сохранять буфер SND_MEMORY живым до остановки.
