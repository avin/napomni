# 08: Ежемесячные и ежегодные напоминания

Календарные правила сохраняют выбранные числа месяца либо пары месяц/день и несколько местных времён. Несуществующая дата пропускается через checked-конструктор даты: 31-е не переносится на последний день короткого месяца; 29 февраля остаётся только в високосных годах, включая пропуск2100 года. Невозможные ежегодные даты и пустые наборы отклоняются до сохранения.

Правила используют общий calendar::first_after и устойчивый calendar_cursor из задачи07. Пропуск времени не сдвигает событие вперёд; повторное местное время допускает только первый UTC-момент. Срабатывания при уже открытой карточке также продвигают курсор, сохраняя сам снимок и sequence. Перезапуск потребляет прошедшие даты и не восстанавливает тосты. Смена зоны пересчитывает будущие местные времена.

Через чат доступны monthly(days,times) и yearly(dates,times), список и результат инструмента получают общее описание расписания. Недельные, интервальные и однократные схемы сохранены.

Проверки: cargo fmt --check, cargo clippy --locked --all-targets -- -D warnings, cargo test --locked. Пять публичных прикладных тестов покрывают короткие месяцы, переход года, високосные годы и2100, невозможные даты, DST gap/fold с двумя временами и перезапуском, пропуски без приложения, сохранение, несколько слотов, удержание открытого снимка и смену зоны. HTTP-сценарий проверяет реальные аргументы двух инструментов, фактические результаты и сохранённые правила без платных запросов.

Новый визуальный прогон настоящих окон Windows не выполнен. Показ использует существующие тосты и команды ядра задачи04.
