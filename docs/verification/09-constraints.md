# 09: Периоды, часы, дни и исключения

Общее правило constrained содержит неизменную основу interval/weekly/monthly/yearly и limits: начальную и конечную местные даты, окно часов, выбранные дни недели и исключённые даты. Все границы включительны. Будни — понедельник–пятница; внешний календарь праздников не используется. Исключение отбрасывает срабатывание и сохраняет исходную интервальную сетку или календарную фазу.

Поиск перескакивает к следующей разрешённой дате/началу окна, затем повторно спрашивает исходное правило. Время срабатывания не подменяется границей окна. Поддерживаются и интервалы длиннее окна: например, каждые2 часа в09–10 при подходящей фазе, либо каждые2 дня по будням. Фильтр действует на местные календарные значения, сохраняя UTC-сетку интервала и календарный курсор повторяющихся местных правил.

Ограничения поиска явные: не более400 календарных лет от более поздней из текущей/начальной дат и100000 проверяемых кандидатов. Если будущий разрешённый момент не найден, создание или изменение отклоняется с объяснением этой границы; это ограничение поддерживаемых сочетаний, а не доказательство математической невозможности. Приближённое расписание не сохраняется. Вложенные ограничения, ограничение однократной даты и окно через полночь отклоняются отдельно; обратные даты, пустые/неверные дни недели и несовместимые календарные времена также дают ошибку.

Для изменения только ограничений инструмент принимает patch.limits: базовая привязка, текст, цвет и звук сохраняются. Пустой объект limits снимает ограничения; действие можно отменить. Успешное окончание периода прекращает будущие срабатывания, сохраняя открытый снимок тоста.

Проверено через Application: включительные границы дат/часов, полчаса09–18 по будням с исключением, выходные и переход месяца, перезапуск, отсутствие сдвига сетки, недельные/месячные/годовые фильтры, широкие интервальные сочетания и явные отказы, изменение/снятие ограничений и отмена без изменения открытого тоста. HTTP-стенд проверяет создание constrained, схему инструмента, реальные факты результата и limits-only очистку с прежней привязкой.

cargo fmt --check, cargo clippy --locked --all-targets -- -D warnings и полный cargo test --locked пройдены. Пять новых прикладных тестов и HTTP-сценарий. Новая визуальная проверка Windows не выполнена; используется подключённый UI списка/чата и существующие тосты.
