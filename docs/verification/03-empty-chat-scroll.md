# Прокрутка пустого чата

Проверено 19 октября 2026 года в настоящем окне GPUI временным примером
`cargo run --locked --example chat_scroll_probe`.
Пример воспроизводил построение истории и `scroll_panel` из `src/ui.rs`,
использовал отдельные `ScrollHandle` для пустой, короткой и длинной истории
и проверял `max_offset().y` после раскладки. Данные пользователя не использовались.

До исправления: `[24px, 0px, 1592px]`, проверка завершалась ошибкой.
После исправления: `[0px, 0px, 1592px]`, проверка прошла.

Причина: для элемента без дочерних элементов GPUI принимает высоту содержимого
равной высоте самого элемента, затем прибавляет вертикальные отступы.
Отступы истории перенесены во внутренний блок; контейнер прокрутки всегда
имеет дочерний элемент и сам не содержит вертикальных отступов.

Временный пример удалён. Постоянного стенда нативного рендеринга в проекте
нет; тест структуры элементов не проверял бы расчёт переполнения GPUI.
Ручная проверка регрессии: открыть пустой чат, добавить короткое сообщение,
заполнить историю до переполнения и очистить её. Полоса должна появляться
только при переполнении.

`cargo test --locked --lib` и `cargo clippy --locked --all-targets -- -D warnings`
прошли. Полный `cargo test --locked` остановился при попытке заменить занятый
`target/debug/win-notifi-toast.exe`. `cargo fmt --check` обнаружил существовавшие
замечания в оформлении списка напоминаний и кнопки закрытия тоста;
их код в этом исправлении не менялся.
